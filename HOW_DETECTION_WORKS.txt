🎯 THE 6 DETECTORS:

1. 📍 IP REPUTATION DETECTOR
   ┌──────────────────────────────────────────────┐
   │ Checks: Is this IP address known as bad?    │
   │ Database: Known botnets, Tor nodes, hackers │
   │ Score: +30 if match found                   │
   │                                              │
   │ Example:                                     │
   │   Login from IP: 203.0.113.50                │
   │   → Check database                           │
   │   → Match: "Botnet C&C Server"               │
   │   → Add +30 points                           │
   │   → Signal: "🚨 Known threat detected"       │
   └──────────────────────────────────────────────┘

2. ❌ FAILED LOGIN DETECTOR
   ┌──────────────────────────────────────────────┐
   │ Checks: Did the login fail?                 │
   │ Logic: Wrong password = suspicious          │
   │ Score: +15 per failure                       │
   │                                              │
   │ Example:                                     │
   │   User enters wrong password                 │
   │   → Login status: FAILED                     │
   │   → Add +15 points                           │
   │   → Signal: "❌ Failed login attempt"        │
   └──────────────────────────────────────────────┘

3. 🔨 BRUTE FORCE DETECTOR
   ┌──────────────────────────────────────────────┐
   │ Checks: Multiple failed attempts?           │
   │ Logic: Looks at last 10 login attempts      │
   │ Score: +25 if 3+ failures                    │
   │                                              │
   │ Example:                                     │
   │   Attempt 1: wrong password (failed)         │
   │   Attempt 2: wrong password (failed)         │
   │   Attempt 3: wrong password (failed) ←       │
   │   → 3 failures detected!                     │
   │   → Add +25 points                           │
   │   → Signal: "🔨 Brute force attack!"         │
   └──────────────────────────────────────────────┘

4. 🌍 GEOGRAPHY DETECTOR
   ┌──────────────────────────────────────────────┐
   │ Checks: Login from new country?             │
   │ Logic: Compares to user's normal locations  │
   │ Score: +20 for new country                   │
   │                                              │
   │ Example:                                     │
   │   User normally logs in from: USA            │
   │   Current login from: Russia                 │
   │   → New country detected!                    │
   │   → Add +20 points                           │
   │   → Signal: "🌍 New country: Russia"         │
   └──────────────────────────────────────────────┘

5. ⚠️ HIGH-RISK REGION DETECTOR
   ┌──────────────────────────────────────────────┐
   │ Checks: Login from risky country?           │
   │ List: Russia, China, North Korea, etc.      │
   │ Score: +15 for high-risk region              │
   │                                              │
   │ Example:                                     │
   │   Login from: Moscow, Russia                 │
   │   → Russia is high-risk                      │
   │   → Add +15 points                           │
   │   → Signal: "⚠️ High-risk region"           │
   └──────────────────────────────────────────────┘

6. 🤖 MACHINE LEARNING DETECTOR
   ┌──────────────────────────────────────────────┐
   │ Checks: Does behavior look weird?           │
   │ Algorithm: Isolation Forest (Scikit-learn)  │
   │ Score: 0-40 based on how weird it is        │
   │                                              │
   │ What it analyzes:                            │
   │   • Time of day (3 AM = weird)               │
   │   • Day of week (Sunday = weird)             │
   │   • Login frequency (too many/few = weird)   │
   │   • Failure rate (lots of fails = weird)     │
   │                                              │
   │ Example:                                     │
   │   User logs in at 3 AM on Sunday             │
   │   → Very unusual time                        │
   │   → ML model detects anomaly                 │
   │   → Add +40 points                           │
   │   → Signal: "🤖 ML anomaly detected"         │
   └──────────────────────────────────────────────┘

🤖 HOW MACHINE LEARNING HELPS:

The ML model learns what "normal" looks like for your users:

Normal Pattern for "alice@company.com":
  • Logs in: Monday-Friday
  • Time: 9 AM - 5 PM
  • From: San Francisco, USA
  • Failure rate: Almost never (< 5%)

When ML sees something different:
  • Logs in: Sunday at 3 AM
  • From: Russia
  • Failed 6 times in a row

ML thinks: "This is VERY different from Alice's normal behavior!"
→ Flags as anomaly
→ Adds score to total risk

📝 SUMMARY:

Q: How does it detect attacks?
A: Uses 6 different detectors that add up points. High score = attack!

Q: What about normal users?
A: Normal users get low scores (0-19) and pass through fine.

Q: What if a user forgets their password?
A: One failure = +15 points (LOW). Not blocked. But 6 failures from 
   Russia at 3 AM from a botnet IP? That's +100 points (CRITICAL)!

Q: How does ML help?
A: ML learns what's normal for each user. When it sees weird behavior
   (login at 3 AM instead of usual 9-5), it flags it.
