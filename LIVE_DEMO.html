🎥 Quick Demo Flow (5 minutes)

Open API Documentation
Click the "API Documentation" link above
Login
Find POST /api/v1/auth/login, click "Try it out", use credentials above, then "Execute"
Authorize
Copy the access_token from response, click "Authorize" button (top right), paste token
View Dashboard
Try GET /api/v1/reports/dashboard to see metrics and analytics
Create Threat Event
Use POST /api/v1/events with suspicious data (Russia/failed login) - watch it auto-generate an alert!
View Alerts
Check GET /api/v1/alerts to see the automatically generated security alert
Manage Alert
Acknowledge or resolve the alert using PATCH endpoints
